# Gestión Académica

Aplicación Flask para registrar cursos y estudiantes, y consultar qué estudiantes pertenecen a cada curso.

## Configuración
1. Crear la base de datos ejecutando `flask_app/bd/esquema_estudiantes_cursos.sql` en MySQL.
2. Revisar usuario y contraseña de MySQL en `flask_app/config/mysqlconnection.py`.
3. Instalar dependencias con Pipenv y ejecutar `server.py`.

La estructura MVC y las rutas se mantienen para conservar el funcionamiento original.
